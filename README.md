# RHREfresh SFX Database Editor
<img align="right" src="gui/src/main/resources/icon/256.png" height="256" width="256">
RSDE is a GUI editor for the [RHREfresh SFXDB](https://github.com/RHREfresh/RHRE-database).

[![Downloads](https://img.shields.io/github/downloads/RHREfresh/RSDE/total.svg)](https://github.com/RHREfresh/RSDE/releases)
[![License](https://img.shields.io/github/license/RHREfresh/RSDE.svg)](https://github.com/RHREfresh/RSDE/blob/master/LICENSE.txt)

## System Requirements
* [Minimum Java 8u60 up to Java 10](https://java.com/en/download/)
* [RHREfresh](https://github.com/chrislo27/RhythmHeavenRemixEditor) to have already been installed and ran at least once
